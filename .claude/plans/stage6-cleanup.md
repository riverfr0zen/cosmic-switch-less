# Stage 6 — Strip template scaffolding leftover from cosmic-app-template

## Context

After stage 4 converted the app to a layer-shell overlay (`no_main_window(true)`, ESC dismisses, render via `view_window`), the original `cosmic-app-template` scaffolding is dead weight: a nav bar with three pages, an About context drawer, a header menu bar, `view()` that renders the nav-based pages, a config struct with one unused field, six Fluent strings none of which are referenced after the dead UI is removed, and several libcosmic features and crates whose only callers are the dead code paths. The packaging files still carry the template's appid (`com.github.riverfr0zen.cosmic-app-template`) and `src/app.rs` even uses the placeholder `APP_ID = "dev.mmurphy.Test"` from the generator.

Goal: delete everything that is no longer reachable from the switcher overlay's runtime path, and rename the remaining template-derived identifiers to match this project.

## Workflow

1. Confirm `main` is clean (no uncommitted changes); copy this plan into the project at `.claude/plans/stage6-cleanup.md`.
2. Commit the plan on `main` (e.g. `docs: plan stage 6 cleanup of template scaffolding`).
3. Create and check out branch `x/cleanup` from `main`.
4. Perform all the code/file changes below on `x/cleanup`, committing in logical chunks (e.g. one commit for app.rs scaffolding removal, one for i18n removal, one for Cargo.toml + features, one for packaging-id rename).
5. Run the verification steps. Do **not** merge into `main` from this session — surface the branch for review.

## Changes

### 1. `src/app.rs` — delete dead UI scaffolding

Keep only what the overlay needs: the layer-shell setup, the wayland subscription, the ESC handler, the windows list, the icon lookup, and `view_window` rendering.

- **State (`AppModel`)**: remove fields `context_page`, `about`, `nav`, `key_binds`, `config`. Keep `core`, `windows`, `window_id`, `desktop_entries`.
- **Messages**: remove `LaunchUrl`, `ToggleContextPage`, `UpdateConfig`. Keep `WindowsUpdated`, `Dismiss`.
- **Methods**: remove `header_start()`, `nav_model()`, `context_drawer()`, `view()`, `on_nav_select()`, `update_title()`. Keep `view_window()`, `update()` (minus the dead arms), `subscription()`, `icon_name_for()`, `window_row()`.
- **Subscription**: remove the `watch_config` arm. Keep `wayland::subscribe()` and the ESC `listen_raw`.
- **Constants**: remove `REPOSITORY` and `APP_ICON`.
- **Enums**: remove `Page`, `ContextPage`, `MenuAction` (and the `MenuAction for MenuAction` impl).
- **`APP_ID`** (line 72): change `"dev.mmurphy.Test"` → `"com.github.riverfr0zen.cosmic-app-switcher"`.
- **Init**: drop the nav setup, the `About::default()` builder, and the `cosmic_config::Config::new(...).get_entry(...)` block. Keep `SurfaceId::unique()`, the `desktop_entries` collection, and the `get_layer_surface` task.
- **Imports**: drop `context_drawer`, `cosmic_config`, `Horizontal`/`Vertical` from alignment, `about::About`, `menu`, `nav_bar`, `HashMap`, and `crate::fl`. Keep `Alignment`, `Length`, `Subscription`, the layer-shell modules, `KeyEvent`/`Key`/`Named`, `Event`, `listen_raw`, `Limits`, `SurfaceId`, `widget::{self, icon}`, the freedesktop entry imports, `PathBuf`.

### 2. `src/main.rs` — remove i18n wiring (keep config module)

- Delete `mod i18n;`.
- **Keep** `mod config;` so `src/config.rs` stays part of the crate as scaffolding for future config additions, even though nothing reads it today. Clippy may emit a `dead_code` warning on the private `demo` field; if so, address with `#[allow(dead_code)]` on the field rather than removing the file.
- Delete the `i18n_embed::DesktopLanguageRequester` block and the `i18n::init` call. The body becomes just the `Settings::default().no_main_window(true).exit_on_close(false)` construction and `cosmic::app::run`.

### 3. Delete files

- `src/i18n.rs` — `fl!` has no remaining callers after step 1.
- `i18n/` directory (whole tree, including `i18n/en/cosmic_app_switcher.ftl`).
- `i18n.toml` if present at repo root (check; the .ftl loader references it).

**Kept**: `src/config.rs` stays in place (user wants it retained as scaffolding for future config use). Its `Config` import in `app.rs` and the `cosmic_config::Config::new(...).get_entry(...)` block both go, since neither does anything functional today; the file itself remains so `mod config;` can be re-added trivially when a field is needed.

**Kept**: `README.autogenerated.md` stays — CLAUDE.md explicitly preserves it.

### 4. `Cargo.toml` — trim deps and features

- Remove crates: `open` (only `LaunchUrl` used it), `i18n-embed`, `i18n-embed-fl`, `rust-embed`.
- Trim libcosmic `features`: remove `about`, `markdown`, `qr_code`, `single-instance`, `xdg-portal`. Keep `wgpu` (renderer) and `wayland` (layer-shell + cctk gates).
- Update `repository = "https://github.com/riverfr0zen/cosmic-app-template"` → `"https://github.com/riverfr0zen/cosmic-app-switcher"`.

### 5. Rename packaging identifiers

Replace `com.github.riverfr0zen.cosmic-app-template` → `com.github.riverfr0zen.cosmic-app-switcher` in:

- `justfile` line 4 (`appid := ...`).
- `resources/app.desktop` line 4 (`Icon=...`).
- `resources/app.metainfo.xml` — the `<id>`, `<launchable type="desktop-id">`, `<provides><id>` fields, and the remote `<icon>` URL host path.

The source icon file at `resources/icons/hicolor/scalable/apps/icon.svg` does not need renaming — the `justfile`'s `install` rule already renames it to `{appid}.svg` at install time (lines 18, 26, 68).
